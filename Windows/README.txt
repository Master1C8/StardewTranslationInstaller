VN Revival Languages for Stardew Valley

1. Extract the entire ZIP archive to a folder.
2. Open "Stardew Translation Installer.exe".
3. The installation starts automatically. When it finishes, choose "Launch game".
   The button starts Stardew Valley through SMAPI so the installed languages load.
4. For future launches, use the "Stardew Valley - VN Revival" desktop shortcut.
   It always starts the installed game through SMAPI, including after SMAPI updates.

Keep the Resources folder next to the application. If Stardew Valley is not
detected automatically, choose the folder that contains Stardew Valley.exe.
